# Document Coauthoring

Use `cliora-project-context`. Identify audience, decision, canonical document, and outcome. Locate related FR, SEC, NFR, API, data, protocol, UX, and test sections. Extend instead of duplicating. Draft the smallest coherent change with assumptions, alternatives, non-goals, and downstream effects across research documents. Preserve IDs and add new ones systematically. Check contradictions, terms, acceptance, failure behavior, security, observability, migration, and tests. Summarize decisions and cross-references.
