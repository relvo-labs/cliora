# Web Design Guidelines

Use `cliora-project-context` and apply `research/style.md` first. Inspect requested files and report terse `file:line` findings with violated rule and fix. When available, fetch current primary Vercel Web Interface Guidelines only as a supplemental checklist; never override local decisions or block offline review. Cover semantics, keyboard/focus, labels, contrast, reduced motion, responsive overflow, forms, tables, dialogs, async feedback, terminal, and file-view accessibility. Label local versus external findings and state source availability.
