# Frontend Design

Use `cliora-project-context`, dashboard patterns, and exact `research/style.md` tokens. Preserve information hierarchy, dense calm industrial surfaces, precise borders, and restrained motion. Prefer sidebar, tabs, tree, split view, terminal, file preview, tables, and keyboard patterns. Make operational state unmistakable. Avoid decorative gradients, excessive glass, marketing typography, playful illustration, and AI-chat styling. Implement with `vue-naive-ui-workflow` and verify accessibility. When style is silent, make the smallest documented extension.
