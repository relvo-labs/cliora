# FastAPI

Use `cliora-project-context`; inspect installed versions, configuration, layout, migrations, and tests. Keep routes thin, authorize at boundaries, delegate business rules, and isolate persistence. Use typed schemas without leaking ORM data or secrets. Scope async sessions and transactions explicitly. Authenticate HTTP and WebSocket handshakes with resource RBAC. Map failures to stable safe codes. Give WebSocket tasks ownership, timeout, cancellation, and cleanup. Test success, invalid input, forbidden, conflict, timeout, disconnect, and rollback. Follow existing commands.
