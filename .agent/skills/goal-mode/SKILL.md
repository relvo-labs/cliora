# Goal Mode

Begin Cliora tasks with `cliora-project-context`. Define outcome, governing research, non-goals, components, risks, steps, and completion checks. Inspect before planning, keep one step active, make bounded changes, and re-plan when evidence changes. Persistence does not authorize production deployment, Git push, external communication, or scope expansion. Complete only when behavior, tests, product/security boundaries, and handoff are satisfied.
