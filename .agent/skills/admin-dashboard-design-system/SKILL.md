# Admin Dashboard Design System

Use `cliora-project-context`; treat PRD flows and `research/style.md` as canonical. Identify actor, primary job, decision, information priority, and dangerous actions. Specify loading, empty, stale, reconnecting, offline, forbidden, partial, error, and success states. Reuse semantic status tokens and never rely on color alone. Preserve density, keyboard access, stable placement, and clear writer/viewer state. Output component, state, data, and acceptance contracts. Use design-system, Vue workflow, and UX review skills as appropriate; do not invent a new aesthetic.
