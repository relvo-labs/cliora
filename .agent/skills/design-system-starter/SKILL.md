# Design System Starter

Use `cliora-project-context`; treat `research/style.md` as canonical. Inventory CSS variables, theme overrides, wrappers, and hard-coded values. Map primitives to semantic surface, text, border, focus, action, feedback, and status tokens. Implement typed Naive UI overrides without duplicate sources. Define xterm and Monaco exceptions. Cover focus, keyboard, disabled, loading, error, contrast, reduced motion, and labels. Migrate incrementally. Do not introduce arbitrary palettes or unsupported themes.
