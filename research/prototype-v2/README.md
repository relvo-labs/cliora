# Cliora V2 前端 Prototype

`research/02/` 那份規劃裡有一批決定，**文字讀不出對錯，要看到、點到才知道**。這份 prototype 就是為了那幾條。

零依賴、無 build：`index.html` + `styles.css` + `app.js`，直接開就能用。

```bash
# 方法一：直接開檔
open research/prototype-v2/index.html          # macOS
xdg-open research/prototype-v2/index.html      # Linux

# 方法二：起一個本機 server（若要從別台機器看）
python3 -m http.server 4430 -d research/prototype-v2
# → http://127.0.0.1:4430
```

頂端黑色工具列是 **prototype 專用的，正式產品不存在**：

- **畫面** 下拉：直接跳到任一畫面（也可以用左側導覽正常瀏覽）。
- **說明模式**：把 `research/02` 的決定與出處貼在對應的 UI 旁邊。**第一次看請打開它。**
- 右側顯示目前視窗尺寸，方便驗窄視窗行為。

## 這份 prototype 的邊界

**它是什麼**：資訊架構、互動語意、視覺分級的檢查工具。

**它不是什麼**：

- 不是實作。沒有 Vue、沒有 API、沒有真實資料，所有內容都是寫死的。
- 不是完整的畫面規格。狀態機只做了拖曳三種拒絕，其餘按鈕多半沒有行為。
- 不含 V1 既有畫面的重繪——那些畫面 V2 不改，重畫只會製造「好像會改」的誤會。
- **沒有做響應式的完整處理**：1100px 以下收右欄、900px 以下收 sidebar，沿用既有斷點，但沒有逐一調校。

## Token 的處置

`styles.css` §1 是既有 token，**與 `frontend/src/theme/tokens.css` 逐字相同，一個都沒改**。
§2 是 V2 新增的候選值，全部集中在一處，並在「Design token 候選」畫面逐項列出色票與 hex。

審查通過之後，那一段才會進 `tokens.css`，並依既有慣例同步 `research/style.md`。**在那之前它們只存在於這份 prototype 裡。**
