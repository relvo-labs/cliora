# Cliora — 五種視覺風格規格

版本：0.1.0 · 狀態：Proposed · 日期：2026-09-09（UTC+08:00）

## 原型與文件的關係

色彩表的「原型值」忠實記錄目前CSS；文字對比修正與各風格布局是下一步規格。現有原型以同一個主要版面展示五種主題，並未完成五張概念圖的全部版型差異。
例如Industrial的水平導覽、Studio的側欄摘要、Midnight的精簡側欄與面板間距仍為提案。

Porcelain與Studio的次文字／主按鈕配對存在未達4.5:1目標的項目；各文件明列改善值。淺色外框下的深色活動分頁也須指定獨立文字色。這些問題記錄為待實作，文件PR不修改原型或已發布預覽。

## 如何選定

先比較主要操作頁，再看Sessions與Nodes延伸。選擇時記錄：

| 決策 | 待填 |
|---|---|
| 主要風格 | 尚未選定；原型預設Graphite不代表使用者已核准 |
| 次要／淺色主題 | 尚未選定 |
| 導覽形式 | 水平／完整側欄／可收合側欄 |
| 預設資訊密度 | 緊湊／標準 |
| 是否混搭 | 指定配色與版型來源；另形成完整定稿 |
| 核准與日期 | 待使用者決定 |

## 文件驗證

本次核對五份風格文件的token鍵、RGB色值、三組文字對比配對及相對連結。對比使用標準sRGB線性化後的相對亮度比值計算，不包含透明度、字型渲染或狀態疊加。
未執行瀏覽器視覺／互動驗收或完整產品測試；各驗收勾選框刻意保持未勾選。
