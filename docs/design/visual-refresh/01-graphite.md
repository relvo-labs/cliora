# Graphite｜石墨專業 — 視覺風格規格

版本：0.1.0 · 狀態：Proposed · 日期：2026-09-09（UTC+08:00）
主題識別：`graphite` · 適用產品：Cliora 遠端操作前端
共同要求：[共用規範](00-shared-foundation.md) · 決策入口：[索引](README.md)

## 1. 視覺定位

沉穩、專注、成熟；讓終端融入工作台，而以青綠選取狀態建立品牌辨識。

主方向的平衡基準。適合日常長時間操作，品牌色與成功色需透過文字及形狀區分。

適用頁面包括 Session 工作台、Sessions、Nodes、概況，以及後續 Enrollment、Audit、Integrations。後三者是風格延伸規格，不表示目前原型已有這些頁面。

## 3. 字體、密度與空間

系統無襯線字體；標題 25px／600，正文 14px／400，操作 14px／500，輔助資訊 12px。

- 終端預設14px，**行高 1.2**，使用者可調12–20px；**修訂（`plan/28`，chromium 實測）：原本寫行高 1.6。**1.6 是 UI 內文的慣例值，而 xterm 的 `lineHeight` 是乘在字格高度上的倍率——在本期目標幾何（1440×900、CLI 面板 674px）下實測，`14px/1.2` 是 **35 列**、`14px/1.4` 是 30 列、`14px/1.6` 只剩 **26 列**，而 `plan/09` 的閘門是 **≥ 30 列**。照字面實作會跌破那道閘門。字體採本機等寬字體，新增字型需隨應用打包。
- UI間距以4px為基本單位：4／8／12／16／20／24／32。
- 表格列48px，表單控制項36px；觸控目標至少44×44px。
- 圓角基準8px；陰影只用於真正浮在內容上的元件。
- 文字縮放至200%時控制項仍可操作，長Session名稱與路徑不得遮住必要動作。

## 4. 桌面版面

完整導覽 **208px**（收合 64px 圖示列）——**修訂（`plan/28`）：原本寫 216px，改為 208px。**208 是 `plan/09` LY-05 量過的值（五個 13px 導覽項含圖示與內距約 144px）；8px 買不到任何東西，卻要動 `tokens.css`、`style.md §9`、`§22` 三處數字並讓 `GATE-LY` 重新校準，所以**改文件不改程式**。右檔案欄預設 258px，可調整 220–360px。頂部導覽 56px、工作標頭 72px、分頁 44px、狀態列 28px。

上述尺寸是此風格的新提案，不是對原型現有尺寸的描述。只由App Shell擁有視窗高度，工作面使用minmax(0, 1fr)及面板內滾動。狀態提示出現時壓縮面板可用高度，不讓整頁產生第二條滾動軸。

終端應取得中央可用面積；CLI、系統終端與預覽分頁一次只顯示一個主面板。不要為看起來像IDE而強制加入多欄分割終端。

## 5. 元件規則

| 元件 | 規則 |
|---|---|
| 導覽與分頁 | 青綠文字＋深青綠底＋2px 左邊線；分頁以2px青綠底線與較高字重表示選中。 |
| 表面、卡片 | 平面、低對比邊界；工作區連成一體，僅對話框與浮層使用陰影。Node 卡片以 1px 邊線區分，卡片不再包卡片。 |
| Primary button | 同一區域只保留一個最高強度動作；使用text.onAccent配對 |
| Secondary／Ghost | 中性底與必要邊界；hover提升背景，不改尺寸 |
| Focus | 2px清楚外框、2px offset；不以hover代替鍵盤焦點 |
| Disabled | 保留標籤；以文字及不可操作語意表示，避免單靠透明度 |
| 表單 | label常駐、錯誤在欄位下方；必填與驗證結果可讀 |
| 狀態標籤 | 成功／離線／重連／結束均帶文字；與runtime標籤分開 |
| 危險操作 | 終止放操作選單並確認Session名稱；不占據日常主動作位置 |
| 表格 | 主要名稱可開啟；路徑為次列；空清單與篩選無結果使用不同文案 |
| 檔案樹 | 展開箭頭、folder/file icon和檔名；選取同時改底色與字重 |
| Toast | 成功短暫提示；失敗保留於相關區域並提供重試 |
| Dialog | 焦點受限於dialog、Esc關閉可取消流程、關閉後返回觸發點 |

## 6. 頁面延伸

- **工作台**：工作標頭顯示Session與Node身份；狀態列分開顯示Session狀態、瀏覽器連線與控制權。
- **Sessions**：名稱與路徑為主欄，Node／Runtime／狀態是比較欄；建立後開啟新工作台。
- **Nodes**：識別、上線狀態、Runtime可用性為第一層；資源資訊不足顯示「無資料」，不用0代替。
- **概況**：繼續工作在指標前；統計顯示回報時間與完整性，不加入不存在的即時監測。
- **管理頁**：Enrollment採表單，Audit採可篩選表格，Integrations採設定群組；沿用本風格元件，不另外建立一套卡片語彙。

## 7. 響應式與動態

- ≥1440px：使用本文件桌面配置。
- 1024–1439px：縮減外距並收合導覽；右側欄保留收合入口。
- 768–1023px：檔案欄改覆蓋抽屜；不將功能直接隱藏。
- <768px：主導覽改可開啟選單，主面板單欄；工作路徑可展開查看；終端輸入跟隨現有授權，不因裝置尺寸自行變更權限。
- 切換狀態120–180ms，縮減動態偏好下停用非必要動畫。
- 終端內容不做淡入、縮放或打字動畫；重連時保留可讀輸出與明確連線狀態。

## 8. 原型差距與實作邊界

原型側欄只有響應式收合，尚未提供桌面手動收合；檔案欄尚不可拖曳調寬。

原型所有畫面採合成資料，無真實終端或遠端授權。正式整合保留既有Vue、Pinia、xterm.js、Monaco與協定（**Naive UI 已於 ADR 0027 §6 移除相依**：它從未被使用——零個元件、一個型別 import、而持有它的檔案沒有被任何檔案 import，所以「保留」它實際上是「導入」它）；視覺變更不得使切換面板卸載仍使用中的終端。
圖稿中的裝飾、區域或延遲資訊不得被當成已有API欄位。

## 9. 禁用與驗收

避免大面積青綠、整頁綠色狀態點與霓虹發光；正常狀態不要比正在工作的內容醒目。

- [ ] 所有使用者需要閱讀的文字配對達到共用可讀性目標，包含終端及狀態標籤。
- [ ] 選中、hover、focus、disabled與error外觀可辨識。
- [ ] 1440×900、1024×768、390×844下核心操作可觸及，無不必要整頁橫向溢出。
- [ ] 長名稱、長路徑、空資料、離線、重連、唯讀、終止及上傳失敗均有畫面。
- [ ] 主題切換保留Session、終端捲動位置、控制權與未送出輸入。
- [ ] 所有量測結果在實作PR中補上；本文件不宣稱已完成瀏覽器驗收。
