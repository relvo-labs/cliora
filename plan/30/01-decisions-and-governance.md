# 01 — 決策與治理（`FD-02`）

## 1. ADR 0028

[`docs/adr/0028-workspace-file-download.md`](../../docs/adr/0028-workspace-file-download.md)。
它是 ADR 0026 結尾清單上唯一一個被**延後**而非被**否決**的項目的設計。

需要特別留意的是 ADR 0026 §4 的那句話不能原封不動鏡射過來：

> the platform does not write to a location, or under a name, that it would
> refuse to show you.

寫入方向成立，讀出方向**只有一半成立**。正確形狀是兩句（ADR 0028 §3）：

```
  平台不會交出它不肯顯示給你看的檔案，   ← 安全規則，與預覽共用同一份實作
  但會交出它只是無法呈現的檔案。         ← 這一期要交付的東西
```

半對比全錯更危險：照抄那一句會把二進位檔一併擋掉，而那正是本功能的理由。

## 3. `file.browse` 的語意變寬，以及它的處置

這是本期唯一一個對既有授權的改動。

- **之前：** 列出、搜尋、預覽（≤2 MiB、UTF-8 文字、非敏感）。
- **之後：** 以上，**加上**取得任何非敏感檔案的完整位元組，
  包含預覽完全拒絕呈現的二進位檔。
- **持有者不變：** Admin、Developer、**Viewer**。

不新增 `file.download` action 的理由見 ADR 0028 §5（動詞相同；三個固定角色
表達不出這個區別；拆開會讓每一個「誰讀過這個工作區」的稽核查詢變成兩個 key 的聯集）。

**代價是真的，處置有三項，缺一不可：**

1. release note 的**第一段**（不是附註）說明語意變寬，並點名 Viewer。
2. 節點開關 `filesystem.download.enabled` 是唯一能保留舊語意的方法，
   所以它是這個決定的**條件**而不是便利。
3. `backend/tests/test_authz.py` 的路由矩陣裡有一列明寫 Viewer 可下載，
   讓日後改變它必須是一個決定，而不是沒人注意到的預設。

## 4. 稽核：新增動作，但不新增 RBAC action

不矛盾，因為兩套詞彙回答不同問題：

- **RBAC 問「誰可以」**，而角色表達不出這個區別（§3）。
- **稽核問「發生了什麼」**，而「讀了一個檔案」與「把一個檔案的拷貝帶走了」
  顯然是不同的事件。

`file.download` 記錄**成功**，這是預覽路徑的**反面**：
`file.sensitive_read_denied` 記錄拒絕，因為成功的預覽什麼都不留下；
成功的下載留下一份平台再也看不到的拷貝。

位元組數記在 `size_bytes` 而不是 `bytes`——後者是 `FORBIDDEN_METADATA_KEYS`
的精確比對項，寫進去會被稽核 API 的輸出過濾掉，等於記了一個沒人讀得到的數字。

## 5. traceability

`FR-FILE-011` 的十條 AC 各有四條連結（planned_by／specified_by／implemented_by／
verified_by）。implemented_by 與 verified_by **刻意指向不同檔案**：
每一列都指向同一份程式與同一份測試會讓矩陣為真但無用。

風險等級依「答錯的代價」定：

| 等級 | 判準 | AC |
|---|---|---|
| critical | 秘密離開節點，或節點內容在 console 網域被渲染 | 02、05、06、10 |
| high | 授權邊界、上限、稽核 | 01、04、08 |
| medium | 功能不動作，或節點姿態被忽略 | 03、07、09 |

## 6. 需要一併修正的既有文案（兩處）

兩處都是**本版起變成假的**陳述，不是順手改的：

1. **`PreviewDenied.vue` 的 `FILE_TOO_LARGE` 分支**寫「MVP 不提供完整載入或下載」。
   從本版起提供，而且 2 MiB 與 4 MiB 之間那一段正是它該說對的地方。
2. **`auditActions.ts` 的 `file.upload` 標籤**寫「投放圖片」。
   ADR 0026 之後這個動作同時涵蓋一般檔案上傳；本期在它旁邊加上「下載檔案」，
   兩者並排會讓舊標籤的錯誤變得刺眼，所以一起改成「上傳檔案」。
   要分辨兩條上傳路徑請看 metadata 的 `source`。
